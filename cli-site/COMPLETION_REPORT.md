```bash

```

**Path 2: Customize It** (15 minutes)
```bash

./portfolio-tui
```

**Path 3: Deploy It** (30 minutes)
```bash
go build -o portfolio-tui
scp portfolio-tui portfolio.yml you@vps.com:/opt/
ssh you@vps.com "cd /opt && ./portfolio-tui"
```
