================================================================================
                        QUICK START GUIDE
================================================================================

OPTION A: Run It Immediately (5 minutes)

  $ ./portfolio-tui
  
  (In another terminal):
  $ ssh -p 2222 user@localhost
  
  (Enter any password, navigate with arrow keys, press 'q' to quit)

OPTION B: Customize & Run (15 minutes)

  $ vim portfolio.yml          # Edit with your info
  $ go build -o portfolio-tui  # Rebuild
  $ ./portfolio-tui
  
  (Connect same as above)

OPTION C: Deploy to Server (30 minutes)

  $ go build -o portfolio-tui
  $ scp portfolio-tui you@vps.com:/opt/
  $ scp portfolio.yml you@vps.com:/opt/
  $ ssh you@vps.com "cd /opt && ./portfolio-tui"
  
  (Others can connect: ssh -p 2222 vps.com)
